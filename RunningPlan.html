8-Week Speed Running Plan

Program Overview

  • Goal: Build speed, power, and running economy
  • Duration: 8 weeks progressive training
  • Structure: 2 Speed Days + 1 Recovery Run + 1 Long Run per week
  • Weekly Volume: 15-28 miles at peak
  • Focus: Dynamic speed work with variety

Pace Guide (Your Reference)

  • Recovery Pace: 10:00-10:30/mile
  • Easy Pace: 9:30-10:00/mile
  • Marathon Pace: 9:30/mile
  • Tempo/Threshold: 8:30-9:00/mile
  • 5K Race Pace: 8:30/mile
  • Interval Pace: 7:30-8:00/mile
  • Sprint Pace: 7:00-7:30/mile (max effort)
  • ✓ Check off runs as you complete them - progress saves automatically!

Program Progression

Weeks 1-3: Build foundation with varied speed work

Week 4: Recovery week (deload)

Weeks 5-7: Peak training - maximum intensity

Week 8: Taper & test your fitness
